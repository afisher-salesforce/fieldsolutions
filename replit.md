# Siemens Mobility | Connected Field Vision

A single-file static HTML executive discussion site for Siemens Mobility, presenting a connected field operating model built on Salesforce capabilities.

## Stack

- Pure HTML/CSS/JS — no build step, no dependencies
- Single entry point: `index.html`
- Assets: `assets/siemens-mobility-header.jpg`

## Running

```
python3 -m http.server 5000
```

The site is served on port 5000 via Python's built-in HTTP server.

## Structure

- `index.html` — entire app (styles, markup, and tab-switching script)
- `assets/` — static images
